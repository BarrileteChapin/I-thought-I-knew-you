Privacy Policy

Last updated: October 2026

Who we are

"I Thought I Knew You" is a student project awarded at the UNESCO Youth Hackathon 2026. This website is a promotional page for the game. It is operated by Mine, Karin, Adrian, and Carlos (the project team).

What data we collect

We collect no personal data. This website does not use cookies, analytics, tracking pixels, or advertising. There is no user account system.

Contact form

The contact form on this page is not connected to any server or inbox. Anything you type stays in your browser and is lost when you close the tab. No form data is transmitted or stored.

The game prototype

The game itself runs entirely in your browser. The chat uses a small language model (approximately 37 MB) that runs on your device. No text you type in the game is sent to any server. No account is required. After one load, the game works offline.

Fonts

This website uses the Space Grotesk typeface, which is self-hosted. No requests are made to Google Fonts or any external font service. Your IP address is not shared with third parties for font loading.

Hosting

This website is hosted on GitHub Pages. GitHub may process server access logs (IP address, timestamp, requested URL) for operational purposes. For details, see GitHub's Privacy Statement.

External links

This site links to external sources (WHO, Pew Research Center, RAND, EdWeek Research Center, Common Sense Media, Mike Caulfield's blog, and the project's source code repository). When you follow these links you leave this site and are subject to those sites' privacy policies.

Children's privacy

This project is designed for teenagers aged 13 and up. Because we do not collect any personal data, no parental consent mechanism is required. The game does not ask for names, email addresses, or any identifying information.

Your rights

Since we do not collect or store personal data, there is nothing to access, correct, or delete. If you have questions about this policy, you can reach the project team through the channels listed on the home page.
